# Evaluasi Pekan 5: Kedai Senja

Aplikasi pencatat transaksi, perhitungan kasir, dan laporan harian berbasis JavaScript untuk UMKM Kedai Senja.

## Deskripsi Singkat
Proyek ini dibuat untuk memenuhi evaluasi pekan ke-5 pembelajaran pemrograman JavaScript, pengelolaan struktur data objek/array, manipulasi DOM dasar, perbaikan bug, serta penerapan alur kerja Git (branching, merging, dan Pull Request).

## Cara Menjalankan
1. Clone repository ini ke perangkat lokal Anda.
2. Buka file `index.html`, `perbaikan.html`, atau `eksperimen.html` di browser pilihan Anda.
3. Buka Console Developer Tools pada browser untuk melihat hasil cetak program.

## Teknologi yang Digunakan
* HTML5
* JavaScript (ES6+)
* Git & GitHub
